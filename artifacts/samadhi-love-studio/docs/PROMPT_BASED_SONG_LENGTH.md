# Prompt-based song length and existing image-video options

The main creator no longer advertises a fixed three-minute default or a six-minute generated-song maximum. Length follows explicit whole-song duration requests first, then lyrics, tempo, phrasing and structure. Estimates remain visible in expandable request details because generation and credit quotes require a duration. Without an explicit time, Studio estimates bars from musical direction and tempo; it does not claim a model-decided unconstrained duration. An explicit whole-song time in the prompt takes priority over a saved song map. Without that explicit time, an enabled map supplies its target. Musical-ad lengths retain their dedicated brief setting.

Connected generation accepts requests from 3 to 600 seconds, with matching input validation, metering limits and manual controls. Subscription credit quantities/prices and cost-per-second calculations remain unchanged. The official composition API reference and composition-plan guide document 3–600 seconds, although the provider's overview currently states a smaller maximum; actual model/account acceptance remains subject to live provider validation. No live ten-minute paid generation was performed. Requests estimated beyond ten minutes are blocked in creation flows with a useful message rather than silently shortened. Standalone local synthesized sketches keep their tested six-minute memory limit; recording/mixing tools keep their existing independent limits.

References: https://elevenlabs.io/docs/api-reference/music/compose and https://elevenlabs.io/docs/eleven-api/guides/how-to/music/composition-plans . Provider-selected duration when music_length_ms is omitted is documented, but this release retains a transparent request estimate to preserve approved-lyric planning and preflight credit confirmation.

Existing Lyric Video → Choose look → Photos to video & advertising supports one uploaded image spanning the selected song/clip, or up to eight images sharing that duration with pan/zoom and dissolve/cut transitions. This existing control has been renamed for easier discovery. General uploaded backgrounds can also apply to all video or individual song sections. Describe-an-image AI generation and generative animation of a photo's subjects remain suggestions; no such provider has been newly connected. Existing photo motion moves the framing, not the person/object inside the picture.

Verification uses the full Studio regression suite, including changed prompt-duration handoffs, ten-minute parsing, tempo-dependent estimates, explicit over-limit rejection, credits and existing photo-story rendering. Browser/mobile and live provider quality remain unverified. No account data or original media were modified for tests.
