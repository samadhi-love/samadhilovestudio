# One song creator and a public listening homepage

Extends the pending creator/video work in the existing SAMADHI LOVE Studio. These source changes require publication of the matching tested build. See STUDIO_CONSOLIDATION.md for scope and verification limits.

The normal creation path is one song editor with Simple and Custom controls. Switching mode expands optional instruments, vocals, language, lyrics and opening controls without discarding the same song's settings. The Video & Shorts Create button routes to this editor. Composer has been removed from navigation, workflow and its editor; existing songs and projects remain saved. Prompt Lab, Vocal Director, the older detailed creation screen and caption-ready production remain optional professional tools rather than competing beginner entry points. The classic video editor is also a professional option. Existing saved work and provider integrations remain intact.

The public homepage uses the existing Community discovery/player for visitors, creators and the owner. My Studio remains separate at the authorized creator/owner routes. Published works populate the feed and artist profiles using existing listens and positive reactions; no fake songs, counts or automatic publication are added. Private drafts do not enter the public feed. Radio remains accessible, with its infrastructure work deferred.

Existing access behavior retained:

| Content/action | Access |
| --- | --- |
| Listed public songs and artist profiles | Anyone, without sign-in |
| Unlisted listening link | Anyone possessing an explicitly generated valid link; outside discovery |
| Private Studio songs, recordings and projects | The owning authorized account |
| Create, save, publish and private library management | Authorized creator account; provider/plan/credit restrictions still apply |
| Reactions, follows, playlists and community participation | Signed-in account, with existing moderation rules |
| Owner/admin functions | Authorized owner only |

Publishing remains an explicit action. Direct social posting is not added: the existing video download, supported device sharing and platform-upload links remain the supported path.

All guided-meditation catalog cards, narration scripts and the guided player—including Be Here Now—have been removed. Saved song audio is not erased. Legacy frequency blends can still open their tone layers without loading narration. Independent frequency tools remain available.
