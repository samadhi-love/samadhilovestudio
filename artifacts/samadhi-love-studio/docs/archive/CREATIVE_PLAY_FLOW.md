# Start → Play → Share

November 14, 2026. Adds a simple creator journey to the existing overview, using QuickCreate, provider billing/confirmation, song storage, audio playback and Lyric Video Pro. No new workspace, account model, schema or automatic social posting is introduced.

## Start

Easy mode offers three feeling starters, own lyrics, Record my voice and Use my recording. A description is optional when supplied lyrics contain performed words. Own voice opens actual Recording Desk; existing audio opens the upload path. It does not claim cloning a voice or copying a hummed melody automatically. Descriptive instructions remain separate from performed lyrics via the existing parser.

Default easy-mode generated songs request 45–90 seconds, without overriding explicit prompt lengths, lyric-driven lengths or enabled song maps. Provider request limits and credits remain enforced. Genre, voice, DNA and detailed settings remain accessible in More choices; the wider Studio and ad tools are retained.

## Play

Successful songs enter Play and can be heard through the existing audio player. Energy and Mood guide the next requested take; Look selects an existing coordinated visual preset. Changing a control itself makes no provider request. Try a new take preserves earlier songs and uses the existing confirmed/quoted provider path. Undo choices restores the previous settings, not a fictitious audio edit. Up to eight recent take references are offered locally; older songs remain in My Songs. A failed generation retains the previous result.

## Share

Keep this opens the finishing choices. Users may attach a JPG/PNG/WebP photo up to 15 MB and choose Make my video. The photo is stored privately against the selected song/source, not sent to a generative model. The existing video editor receives the chosen look, vertical framing and optional photo. A recording-ID guard rejects stale handoffs. Original words, source audio, timeframe and inactive ad media are preserved by the visual helper.

Vocal caption alignment uses the existing flow; creators review accuracy/timing and render through existing controls. Audio downloads remain available separately. Nothing is automatically posted, billed as an ad campaign or silently generated merely by choosing Look. There is no guarantee of a ten-minute end-to-end turnaround, a consistent AI singer, selective melody inpainting or instant AI video.

Recovery retains choices, recent result/take references and an optional photo blob using existing account-scoped device recovery. Original saved songs are never replaced by the new-take action. Photos are added after music creation in this first release; they are not analyzed to invent the music.

## Verification

The main verifier passed 37 groups. The final targeted creator suite passed five tests covering generation/selected look, multiple retained takes, non-generating control changes, failed requests, exact own lyrics, explicit durations, recording/upload callbacks, immutable visual handoff and lyrics-only starts. TypeScript and a final production build passed after the lyrics-only refinement.

Browser control was unavailable. Real phone layout, latency, microphone capture, photo pickers, live provider output quality, native video encoding and device sharing remain unverified. “Fast and easy” is the design goal, not an unmeasured performance guarantee.
